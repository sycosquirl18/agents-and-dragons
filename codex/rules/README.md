# Rules

One resolution mechanic: **`1d20 + modifier` vs a DC.** Everything below is an application of that. If a proposed
rule needs a different mechanic, it is probably the wrong rule.

| File | |
| --- | --- |
| [checks.md](checks.md) | Stats, DCs, advantage, crits — **the atom, read this first** |
| [scenes.md](scenes.md) | How play actually runs: the question-and-answer loop — **read this second** |
| [combat.md](combat.md) | Danger, harm, dying, and getting out |
| [character-creation.md](character-creation.md) | Rolling up a new hero |
| [magic.md](magic.md) | Cinder-glass casting, glass grades, Load and carrying |
| [traditions.md](traditions.md) | The three inscription hands, and how they react to each other |
| [economy.md](economy.md) | Coin, prices, wages, loot |
| [spells/](spells/README.md) | The spells that exist |

Those three build on each other: `checks` is one roll, `scenes` is a sequence of rolls, `combat` is a sequence of
rolls that can kill you. Nothing else is a subsystem.

## Missing rules

Written by [Rules Smith](../../.github/workflows/rules-smith.md) as play demands them, not in advance. Currently
unwritten and known to be needed:

- **travel.md** — tide-dependent movement, journey length, encounter frequency
- **downtime.md** — what a hero does between quests
- **reputation.md** — how factions come to like or hate a hero

If you had to improvise a ruling, open a `rules-gap` issue rather than writing the rule inline.

## Precedent

A rule change never invalidates something that already happened. Old rulings stood at the time they were made; the
[Chronicle](../chronicle/README.md) keeps its own physics.
