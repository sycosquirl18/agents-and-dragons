## What belongs here

A moment gets a file when it is **argued about**. If everyone agrees what happened and why, one line in the era file
is enough.

Recent happenings go in the [Chronicle](../../../chronicle/README.md) first. The
[Chronicler](../../../../.github/workflows/chronicler.md) promotes one here only once it is old enough that people
have started disagreeing about it — which in practice means about a decade.
