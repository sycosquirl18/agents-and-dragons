# Geography

The known world is a drowned coast, a scar, and the dry country behind them.

| Region | |
| --- | --- |
| [Vaultspire](regions/vaultspire.md) | Salvage city built into a half-sunk kiln-vault; the party's home port |
| [The Saltmarch](regions/the-saltmarch.md) | The drowned coast — a hundred miles of tidal ruin |
| [The Glass Wound](regions/the-glass-wound.md) | The scar the Sundering opened; source of all cinder-glass |
| [The Ashfields](regions/the-ashfields.md) | Dry farmland inland; feeds Vaultspire and resents it |

## How travel works

Distances are measured in tides, not miles. The Saltmarch is passable only at low water, so a journey's length depends
on when you start. Overland routes through the Ashfields are slower but do not care about the moon.
